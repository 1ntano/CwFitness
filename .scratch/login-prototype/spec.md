# CwFitness 登录页视觉原型

Status: resolved

## 目标

在不接入真实认证后端的前提下，探索三个符合 CwFitness 深色、低饱和度、tvOS 感的登录页方向，并验证登录、显示密码、注册入口与找回密码入口。

## 方向

- Immersive：全屏影像与左侧轻量玻璃面板。
- Spotlight：中央聚焦的系统式玻璃卡片。
- Split：品牌叙事与表单明确分区。

## 验收

- 三个方向可通过选择器、数字键及左右方向键切换。
- 表单具备标签、自动填充语义、错误反馈与键盘焦点。
- 登录提交有等待及成功反馈，但不发送或保存真实凭据。
- 支持减少动态、减少透明度和高对比度偏好。
- 1440×1000 与 390×844 视口均可使用。
