# Training tools and BMR calculator

## Goal

Give Users local training utilities that do not depend on editing plan or history data.

## Scope

- A Tools view reachable from the main navigation.
- Recommended Exercise video links grouped by Muscle Group.
- A Basic Metabolic Rate (BMR) calculator.

## Success criteria

- The Tools view is responsive and follows the existing workspace visual language.
- Recommended Exercises are grouped by the same Muscle Group taxonomy used by Exercise.
- Bilibili links open a demo-video search for the selected Exercise.
- BMR calculation is local and does not call a server API.
